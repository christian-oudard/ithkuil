# Published versions of the source documents

Version history as published by Quijada. The reference documents in
this directory carry only the current version; the superseded wording
is not reproduced.

## NEW ITHKUIL: GRAMMAR DESIGN

Current version 1.3.2 (Feb. 15, 2023), which updates and replaces
version 1.2.1 of January 18, 2023.

**Version 1.3:**

- **Sec. 3.6:** Two of the allomorphic substitutions for C_A have been modified.
- **Sec. 3.9.1:** The meaning of the **PAR** inverse case-accessor has been augmented.
- **Sec. 3.9.3.3:** The presentation of V_K Illocution and Validation phonological values has been simplified.
- **Sec. 4.2:** The Slot IV V_R Values for the Specialized C_S-Root now show Degree plus Context, instead of Degree plus Specification, as it did not make sense for these Specialized C_S-Roots to show any Specification other than BSC given that Specification does not apply to V_X C_S affixes.
- **Sec. 4.4:** The **CAR** Carrier-End Register Adjunct has been relabeled to **END**. The **MTH** Register Adjunct has been eliminated and the **CGT** Register adjunct value changed.
- **Sec. 4.5:** Each of the Suppletive Adjuncts has now been assigned a Label for use in intralinear analyses: **CAR, QUO, NAM, PHR**.
- Mood/Case-Scope Adjuncts have been eliminated; use the new **MCS** affix instead (see Affixes document).
- **Sec. 5.8:** The example sentences for the **CHC** affix have been revised, corrected and expanded.
- **Sec. 7.4:** Various examples updated/corrected.

**Version 1.3.1:**

- **Sec. 3.9.2:** A note has been added regarding constraints/limitations on the use of Type-3 affixes.
- **Sec. 3.9.3.1:** The table providing descriptions of the nine validations has been reinstated.
- **Sec. 5.8:** A few typos in the example sentences have been corrected.

**Version 1.3.2:**

- **Sec. 3.9.3.3:** The 3-letter abbreviation for VERIFICATIVE Illocution has been changed to **VER**.
- **Sec. 4.7:** The 3-letter abbreviation of ADMISSIVE Bias has been changed to **ADS**. The EXPERIENTIAL Bias has been renamed the **MNF** MANIFESTIVE Bias, and the RENUNCIATIVE Bias has been renamed the **RSG** RESIGNATIVE Bias.

## VXCS AFFIXES FOR NEW ITHKUIL

Current version 1.1 (Feb. 11, 2023), which updates version 1.0.1.

**Version 1.1:**

- The description of Gradient Type A2 affixes has been corrected.
- The phonological value of the **XXZ** affix has been changed to match its corresponding root.
- **DCD**/5 has been updated. **ST2**/1 and **ST2**/9 have been swapped.
- **MCS**/9 has been corrected.
- The **IVL** affix has replaced the **IVE** affix.
